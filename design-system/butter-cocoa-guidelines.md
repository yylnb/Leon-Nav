# 黄油可可配色规范

这份规范把 `palette-options-v3` 中的“黄油可可”确定为 YY 系列网站的默认品牌配色。以后新建网站、页面、组件或营销物料时，优先使用本文件中的语义角色，而不是临时挑选相近颜色。

配色来源：[palette-options-v3.html](./palette-options-v3.html) 的方案一“黄油可可”。

组件展示页：[butter-cocoa-guidelines-demo.html](./butter-cocoa-guidelines-demo.html)。

## 1. 配色组成

| 颜色角色 | 名称 | HEX | 主要用途 | 默认文字色 |
| --- | --- | --- | --- | --- |
| `brand-primary` | 黄油黄 | `#FFE27A` | 页面主背景、品牌标识、主视觉、浅色区域 | 可可棕 `#3A1C10` |
| `brand-deep` | 可可棕 | `#3A1C10` | 正文、标题、深色块、主按钮、导航文字 | 黄油黄 `#FFE27A` |
| `brand-accent` | 钴蓝 | `#2443FF` | 链接、提示、焦点环、少量图形和强调 | 白色 `#FFFFFF` |

颜色的气质是“柔和的黄 + 有温度的深色 + 一小块高饱和蓝”。黄油黄负责识别度，可可棕负责阅读和稳定感，钴蓝负责引导视线。钴蓝应当像标点一样出现，不能和可可棕争夺页面主导权。

## 2. 页面配色比例

使用 **60 / 30 / 10** 作为视觉面积的起点：

- **60% 黄油黄或中性浅色面**：页面外壳、Hero 区、品牌横幅、空状态和大块背景。
- **30% 可可棕**：正文、标题、导航、深色卡片、主按钮和需要稳定承托的区域。
- **10% 钴蓝**：链接、提示、小插图、选中状态、焦点反馈和关键数字。

这是视觉面积比例，不要求每个页面精确计算像素。内容密集的工具页可以使用白色作为阅读表面，但品牌区域仍应保留黄油黄，文字和主要操作仍使用可可棕，钴蓝只承担交互提示。

不要把三种颜色平均分成三块，也不要同时让大面积钴蓝和大面积可可棕相邻。钴蓝与可可棕之间应隔着黄油黄或白色。

## 3. 颜色语义和使用规则

### 黄油黄 `#FFE27A`

适合用在整页背景、首屏、品牌标识、宣传卡片、选中但不危险的背景和大面积留白区域。它可以铺满页面，仍然保持轻快和温暖。

黄油黄上只放可可棕文字、图标或边框。黄油黄上不要放白色正文，也不要把浅灰文字直接压在上面。钴蓝可以作为小型链接或图标使用，但正文链接应加下划线或提高字重。

### 可可棕 `#3A1C10`

它是默认的文字色和主要操作色，适合正文、标题、导航、页脚、深色卡片、标签文字和主按钮。可可棕比纯黑更柔和，适合长时间阅读。

可可棕背景上优先使用黄油黄文字。需要更高的可读性时可以使用白色文字，但白色文字会削弱品牌色的关系，优先级低于黄油黄文字。可可棕背景上不要直接放钴蓝文字或钴蓝图标。

### 钴蓝 `#2443FF`

钴蓝只做强调色：链接、提示、焦点环、选中状态、少量插图、图表中的重点系列和小面积装饰。它不是默认的页面背景，也不是所有按钮的颜色。

在白色或黄油黄背景上使用钴蓝链接时，始终保留下划线或其他非颜色提示。钴蓝背景上使用白色文字；钴蓝背景上不要使用可可棕文字。

## 4. 推荐的语义 Token

组件代码应引用语义 Token，避免在业务页面里到处写 HEX：

```css
:root {
  --color-brand-primary: #FFE27A; /* 黄油黄 */
  --color-brand-deep: #3A1C10;    /* 可可棕 */
  --color-brand-accent: #2443FF;  /* 钴蓝 */

  --color-surface: #FFFFFF;
  --color-text: var(--color-brand-deep);
  --color-text-muted: color-mix(in srgb, var(--color-brand-deep) 68%, white);
  --color-border: color-mix(in srgb, var(--color-brand-deep) 18%, white);

  --color-link: var(--color-brand-accent);
  --color-focus: var(--color-brand-accent);
  --color-button-primary-bg: var(--color-brand-deep);
  --color-button-primary-text: var(--color-brand-primary);

  /* 用于提示标签的浅色衍生色，不替代三种品牌主色 */
  --color-butter-soft: #FFF3C4;
  --color-butter-ink: #5C4A00;
}
```

如果项目不支持 `color-mix()`，请在项目的 Token 文件中预先定义等价的静态值，不要在组件中临时混入新的色相。

## 5. 按钮规范

默认按钮采用圆角胶囊形，边框至少 `2px`，高度保持在 `40–48px`。按钮文字使用中等或粗体，保证在小尺寸下仍然清楚。推荐的基础尺寸与 `palette-options-v3` 中的示例一致：水平内边距 `18px`、垂直内边距 `11px`、圆角 `999px`。

### 主按钮

主按钮用于页面最重要的动作，例如“开始使用”“保存”“打开关注清单”。

```css
.button-primary {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-height: 44px;
  padding: 11px 18px;
  border: 2px solid var(--color-brand-deep);
  border-radius: 999px;
  color: var(--color-brand-primary);
  background: var(--color-brand-deep);
  font: inherit;
  font-weight: 800;
  cursor: pointer;
}

.button-primary:hover {
  filter: brightness(0.92);
}

.button-primary:active {
  transform: translateY(1px);
}
```

主按钮不要使用黄油黄背景配白字，也不要默认使用钴蓝填充。黄油黄背景上的白字对比度不足；钴蓝应保留给链接和少量强调。

### 次按钮 / Quiet Button

次按钮用于次要动作，例如“取消”“稍后订阅”“查看详情”。它不应与主按钮争夺视觉重量。

```css
.button-quiet {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-height: 44px;
  padding: 11px 18px;
  border: 2px solid var(--color-brand-deep);
  border-radius: 999px;
  color: var(--color-brand-deep);
  background: transparent;
  font: inherit;
  font-weight: 800;
  cursor: pointer;
}

.button-quiet:hover {
  color: var(--color-brand-deep);
  background: var(--color-butter-soft);
}
```

### 钴蓝操作

钴蓝按钮只用于需要“提示、跳转或强调”的轻量动作，例如“查看方法”“打开帮助”。如果确实需要钴蓝底，使用白色文字，并把按钮数量控制在页面少数位置。

```css
.button-accent {
  border: 2px solid var(--color-brand-accent);
  border-radius: 999px;
  color: #FFFFFF;
  background: var(--color-brand-accent);
}
```

### 禁用和焦点状态

- 禁用按钮保留原来的色彩关系，使用 `opacity: 0.45`、`cursor: not-allowed` 和去除阴影表示不可用，不要改成新的彩色。
- 所有键盘可聚焦控件都必须有清晰的 `:focus-visible` 状态。默认使用 `3px` 钴蓝外轮廓，`outline-offset: 3px`。
- 当控件本身是钴蓝底时，焦点环改用可可棕或白色，确保轮廓能被看见。

```css
:where(button, a, input, select, textarea):focus-visible {
  outline: 3px solid var(--color-focus);
  outline-offset: 3px;
}
```

## 6. 链接、导航和标签

正文链接默认使用钴蓝，并使用 `2px` 下划线和 `4px` 下划线偏移；悬停时可以增加字重或降低背景亮度，不要只靠颜色变化表达状态。

```css
a {
  color: var(--color-link);
  text-decoration: underline;
  text-decoration-thickness: 2px;
  text-underline-offset: 4px;
}
```

导航中的当前项可以使用可可棕文字配黄油黄底，也可以使用钴蓝下划线。当前项不建议只显示成一块纯钴蓝色，因为钴蓝在导航里会过度抢眼。

提示标签、已更新标签和轻量状态可以使用 `#FFF3C4` 背景配 `#5C4A00` 文字。标签采用胶囊形，字号小于正文时应提高字重，并确保状态仍然有文字说明。

## 7. 卡片、表单和内容区域

- **深色卡片**：可可棕背景 + 黄油黄标题或重点数字。适合重点结论、品牌介绍和高优先级摘要。
- **浅色卡片**：白色或黄油黄背景 + 可可棕文字。适合正文、表单、数据列表和阅读区域。
- **强调卡片**：白色或黄油黄背景 + 钴蓝图形或左侧标记。钴蓝面积保持小块，不要把整张内容卡片涂成钴蓝。
- **输入框**：白色背景、可可棕文字、可可棕低透明度边框；聚焦时使用钴蓝边框或焦点环。
- **分割线**：使用可可棕的低透明度版本，不要使用高饱和钴蓝分割整页内容。
- **图标**：默认可可棕；交互图标和提示图标使用钴蓝；不要用三种颜色同时填满同一个小图标。

表单错误、成功、行情涨跌等信息仍然使用独立的状态色，不能用钴蓝代替错误或成功，也不能用品牌色取代用户已经熟悉的语义色。金融页面可以沿用项目已有的红涨绿跌规则，并通过文字、符号或图标补充含义。

## 8. 对比度与允许的颜色组合

以下组合是规范中的默认安全组合；比例为近似值，具体组件仍需在实际字号、字重和背景上检查。

| 背景 | 前景 | 对比度 | 结论 |
| --- | --- | ---: | --- |
| 黄油黄 `#FFE27A` | 可可棕 `#3A1C10` | 12.1:1 | 正文、标题、按钮文字均可 |
| 可可棕 `#3A1C10` | 黄油黄 `#FFE27A` | 12.1:1 | 深色块、主按钮均可 |
| 钴蓝 `#2443FF` | 白色 `#FFFFFF` | 6.3:1 | 钴蓝按钮和小面积强调可用 |
| 白色 `#FFFFFF` | 可可棕 `#3A1C10` | 15.5:1 | 正文和表单均可 |
| 白色 `#FFFFFF` | 钴蓝 `#2443FF` | 6.3:1 | 链接和提示可用 |
| 黄油黄 `#FFE27A` | 钴蓝 `#2443FF` | 4.9:1 | 链接或粗体小标题可用，建议保留下划线 |
| 黄油黄 `#FFE27A` | 白色 `#FFFFFF` | 1.3:1 | 禁止用于正文和按钮文字 |
| 可可棕 `#3A1C10` | 钴蓝 `#2443FF` | 2.5:1 | 禁止直接叠放 |
| 钴蓝 `#2443FF` | 可可棕 `#3A1C10` | 2.5:1 | 禁止直接叠放 |

涉及小字号正文时，以至少 `4.5:1` 的对比度为最低要求；大字号文字最低 `3:1`。颜色对比合格不等于信息表达完整，链接、错误和选中状态还要配合下划线、图标、文字或形状变化。

## 9. 不要这样使用

- 不要使用纯黑替代可可棕，除非第三方组件或系统控件无法改色。
- 不要把黄油黄背景配白色正文或白色按钮文字。
- 不要把钴蓝文字直接放在可可棕背景上。
- 不要把钴蓝、可可棕和黄油黄做成同等面积的三栏彩条。
- 不要让大面积钴蓝取代页面主背景；钴蓝应该是引导色。
- 不要用品牌色表达成功、错误、警告或行情涨跌等既有语义。
- 不要通过降低文字透明度来修复错误的底色搭配；先换成允许的前景色。

## 10. 新页面交付前检查

1. 页面是否能明确看出黄油黄、可可棕、钴蓝各自的角色，而不是三种颜色随机出现？
2. 主背景、内容区域和强调色是否大致遵循 60 / 30 / 10？
3. 所有正文是否使用可可棕或白色，而不是把钴蓝当正文色？
4. 主按钮是否为“可可棕底 + 黄油黄字”？次按钮是否降低了视觉重量？
5. 链接是否使用钴蓝并保留下划线或其他非颜色提示？
6. 是否存在黄油黄底白字、钴蓝底可可棕字或钴蓝与可可棕直接相邻的组合？
7. 键盘焦点、禁用、错误、成功和行情状态是否都能在不依赖颜色的情况下被识别？
8. 新增的衍生色是否只是为了交互状态或中性色阶，并且没有改变三种品牌主色的关系？

这套规范的核心顺序是：先用黄油黄建立品牌场景，再用可可棕完成阅读和主要操作，最后用钴蓝告诉用户“这里可以点击、这里值得注意”。
